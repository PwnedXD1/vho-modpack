# Vulkan HEAVENLY Optimized (VHO)

Welcome to the official issue tracker for **Vulkan HEAVENLY Optimized (VHO)**, a minecraft optimization pack to get best performance

**Download the modpack:** https://modrinth.com/modpack/vulkan-heavenly-optimized
 
## Supported Platforms

We officially test and provide support for the following operating systems:

**Windows 10 / 11**

**Linux** (mostly wayland)

**FreeBSD** 

*macOS is not supported. but coming soon*

## How to Report a Bug

Before opening a new issue, please follow these simple rules so we can help you faster:

1. Search existing issues... check the [Issues tab](https://github.com/PwnedXD1/vho-modpack/issues) (including closed ones) to see if your problem has already been reported or fixed
2. Use the Bug Report template... click "new issue" and fill out all the requested details (Modpack version, OS, GPU, and Driver/Mesa version)
3. Attach your logs.... Always drag and drop your `latest.log` or `crash-report` file into the report. issues without logs are very hard to fix
4. Mention extra mods... If you added any third party mods resource packs or shaders to the pack please list them. we cannot guarantee compatibility with custom modifications


## Need Help or Have Suggestions?

Found a crash or visual glitch? Open a **[Bug Report](https://github.com/PwnedXD1/vho-modpack/issues)**.

Have an idea to improve performance or mod compatibility? Feel free to open an issue and describe your suggestion!
